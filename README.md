# SmartKrishi Share

A full-stack rural resource sharing platform for equipment rental, crop marketplace, and labor hiring.

## Setup

### Backend

1. cd server
2. npm install
3. Create a `.env` file with:
   - MONGO_URI=
   - JWT_SECRET=
4. npm run dev

### Frontend

1. cd client
2. npm install
3. npm start

## Features

- User auth (register/login)
- Farmer dashboard
- Admin dashboard
- Equipment sharing and bookings
- Crop marketplace, weather, and government schemes support planned
